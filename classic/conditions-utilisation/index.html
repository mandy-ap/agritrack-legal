2. Description de l'Application

AgriTrack Classic est une application mobile de gestion avicole infonuagique destinée aux petits producteurs. Elle permet notamment de :

  • Suivre les élevages, enclos et cycles de production d'œufs
  • Gérer les couvées et incubateurs
  • Enregistrer les dépenses liées à l'exploitation
  • Gérer les ventes, commandes et fournisseurs
  • Consulter des statistiques de production

L'Application nécessite une connexion Internet et un compte utilisateur pour fonctionner. Les données sont stockées de façon sécurisée sur des serveurs infonuagiques situés au Canada.
